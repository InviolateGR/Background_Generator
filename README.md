# Gradient Backgrounds

A modern web tool to generate beautiful CSS gradients instantly.  
Pick themes, rotate directions, randomize colors, and copy CSS.

## Features

- Multiple gradient categories: Cool, Warm, Vibrant, Dark, Light, Rustique, Pastel, Neon
- Rotate gradients and copy CSS instantly
- Keyboard shortcuts: `R` = rotate, `C` = copy, `X` = random
- Fully responsive layout
- Clean, smooth animations

## Live Demo

[GitHub Pages Link Here](https://YOUR_USERNAME.github.io/Background_Generator/)

## Usage

1. Open `index.html` in a browser.
2. Pick a gradient category.
3. Use buttons or keyboard shortcuts to rotate, randomize, and copy.
4. Copy CSS directly into your projects.
